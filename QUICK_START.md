# DinoExpedition - Quick Start Guide

## 🚀 Running the App

```bash
cd example
fvm flutter run
```

Or without FVM:
```bash
cd example
flutter run
```

## 📱 What's New

DinoExpedition is now a complete archaeological adventure game:

### Main Features
1. **Home Screen** - Dashboard with stats and missions
2. **Dig Sites** - Excavate fossils in various locations
3. **Museum** - Display your dinosaur collection
4. **Workshop** - Upgrade your excavation tools
5. **Cards** - Manage support card deck
6. **Research** - Conduct scientific studies
7. **Profile** - View achievements and stats
8. **Settings** - Customize game experience

### Gameplay Loop
1. Select a dig site
2. Tap blocks to excavate
3. Discover dinosaur fossils
4. Earn coins and experience
5. Upgrade tools
6. Complete dinosaur collections
7. Build your museum
