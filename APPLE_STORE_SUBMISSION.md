## App Description

### Full Description

DinoExpedition is an immersive archaeological adventure game. Excavate dinosaur fossils, restore ancient skeletons, conduct scientific research, and build an impressive museum. Features strategic excavation, 52+ dinosaur species, tool upgrades, and 52 original Expedition Boost cards across diverse dig sites.
